Movie Rating Prediction using Python

Project Overview

This project focuses on predicting movie ratings using Machine Learning techniques in Python.

The project uses the IMDb India Movies dataset to explore movie-related information, process the data, and build a predictive model to estimate movie ratings.

Objectives

- Understand and preprocess movie datasets.
- Clean and prepare data for Machine Learning.
- Train a regression model to predict movie ratings.
- Generate predictions and evaluate model performance.
- Visualize important patterns and results.

Dataset

Dataset: IMDb Movies India

The dataset contains information about Indian movies, including relevant features used for rating prediction.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

Project Files

- "movie_rating_prediction.py" – Main Python implementation.
- "cleaned_movies.csv" – Cleaned dataset.
- "prediction_results.csv" – Generated prediction results.
- "movie_rating_model.pkl" – Saved trained model.
- Charts folder – Visualizations generated during the project.

How to Run

1. Install the required Python libraries.
2. Keep the original dataset in the project directory.
3. Open the terminal in the project folder.
4. Execute:

py movie_rating_prediction.py

Project Outcome

Successfully developed and executed a Machine Learning regression project that generates movie rating predictions and produces visualizations and model outputs.
